# Embassy Visa Issuance Package (After COE)

Use this folder for the visa application at the Japanese embassy/consulate in your home country after COE issuance.

## Official sources
- MOFA Start-up Visa page: https://www.mofa.go.jp/ca/fna/page22e_000873.html
- MOFA designated activities visa page: https://www.mofa.go.jp/j_info/visit/visa/long/visa13.html
- Embassy/consulate directory: https://www.mofa.go.jp/about/emb_cons/over/index.html

## Required documents checklist
- [ ] 01 Passport
- [ ] 02 Visa application form
- [ ] 03 Photograph(s)
- [ ] 04 Certificate of Eligibility (original/copy or printed e-COE)
- [ ] 05 Nationality-specific additional documents (if required)

## How to obtain
- Visa application form:
  - Download from the website of the Japanese embassy/consulate where you will apply.
  - Use the form version explicitly required by that post.
- Additional documents:
  - Check your local embassy page for nationality-specific requirements and appointment rules.
  - Some posts require extra civil documents or local residence proof.

## Important note
- Embassy-level requirements can differ by country and nationality. Always follow your local Japanese embassy/consulate instructions as final.
