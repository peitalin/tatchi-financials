# Immigration COE Package (Designated Activities)

Use this folder for Certificate of Eligibility submission after receiving Tokyo's confirmation certificate.

## Official sources
- Tokyo Startup Visa process page: https://www.investtokyo.metro.tokyo.lg.jp/en/oursupports/bdc-tokyo/startupvisa.html
- Tokyo Startup FAQ: https://www.investtokyo.metro.tokyo.lg.jp/en/oursupports/bdc-tokyo/startup-faq.html
- ISA procedures index: https://www.moj.go.jp/isa/applications/procedures/index.html

## Required documents checklist
- [ ] 01 Application for Certificate of Eligibility for Status of Residence
- [ ] 02 Photograph (3 cm x 4 cm, taken within 6 months)
- [ ] 03 Copy of passport
- [ ] 04 Return envelope with required stamps and reliable Japan contact address
- [ ] 05 Full copy set of documents previously submitted to Tokyo
- [ ] 06 Copy of Startup Preparation Activity Plan Confirmation Certificate (valid within 3 months)

## How to obtain
- COE application form:
  - Go to ISA procedures index and select the current COE application form for the applicable status/procedure.
  - If unsure, confirm the exact form at TOSBEC immigration booth before submission.
- Photograph:
  - Use a compliant ID photo service; keep digital and print versions.
- Return envelope:
  - Prepare a self-addressed Japanese domestic envelope with required postage according to latest immigration instructions.
- Tokyo copy set:
  - Export one complete PDF set of all items you sent to Tokyo in Step 1.
