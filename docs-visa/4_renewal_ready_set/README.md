# Renewal Ready Set (6-Month Extension Path)

Use this folder if a renewal of Designated Activities is needed before switching to Business/Management.

## Official sources
- Tokyo Startup Visa page (renewal section): https://www.investtokyo.metro.tokyo.lg.jp/en/oursupports/bdc-tokyo/startupvisa.html
- Tokyo implementation outline (updated): https://www.investtokyo.metro.tokyo.lg.jp/jp/oursupports/Guidelines_202510.pdf
- METI revised notice (effective 2025-10-16): https://www.meti.go.jp/policy/newbusiness/startupvisa/kokuji_20251016.pdf

## Required documents checklist
- [ ] 01 Form 1-2: Startup Preparation Activity Plan Renewal Confirmation Application and Consent
  - Direct link: https://www.investtokyo.metro.tokyo.lg.jp/en/oursupports/bdc-tokyo/form_1-2.docx
- [ ] 02 Updated Form 1-3: Startup Preparation Activity Plan
  - Direct link: https://www.investtokyo.metro.tokyo.lg.jp/jp/oursupports/bdc-tokyo/Form%201-3.docx
- [ ] 03 Updated Form 1-4: Resume
  - Direct link: https://www.investtokyo.metro.tokyo.lg.jp/jp/oursupports/bdc-tokyo/Form%201-4.docx
- [ ] 04 Copy of passport
- [ ] 05 Proof of residence for 6 months after renewal
- [ ] 06 Proof of living funds for 6 months after renewal
- [ ] 07 Other supporting documents (if requested)
- [ ] 08 Progress evidence to support renewal review (recommended)

## How to obtain (non-download documents)
- Residence/funds proof:
  - Collect lease/residence and bank documents clearly covering the next 6 months.
- Progress evidence:
  - Prepare dated evidence (office setup progress, hiring activity, partner/customer progress, contracts, etc.).

## Timing note
- Prepare and submit renewal materials before the current period of stay expires.
